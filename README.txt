HANIA'S CLOSET WEBSITE + CHATBOT

This version includes:
- REAL fashion photos for dresses
- REAL product-style shoe photos
- REAL handbag photos
- REAL jewellery photos
- Category filters
- Price chatbot

IMPORTANT:
The fashion photos are loaded from Pexels online, so an internet connection is needed for the real photos to appear. The website and chatbot work locally.

HOW TO RUN:
1. Extract the ZIP.
2. Open index.html in Chrome.
3. Turn ON internet so all real photos load.
4. Use the category buttons to view Dresses, Shoes, Bags and Jewellery.
5. Ask the chatbot about prices.

Example:
“How much is the Luxury Handbag?”
